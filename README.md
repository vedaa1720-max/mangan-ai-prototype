# MANGAN-AI Enhanced Web Prototype

## What's new
- New cinematic starting / welcome page.
- Horizontal feature strip on the dashboard for quick access to all major modules.
- Existing dashboard, map, controls, forecast, risks, recommendations and methodology retained.
- Responsive layout for smaller screens.

## Public QR
A QR code can open the prototype directly only after the site has a public HTTPS URL. This package includes `QR_LIVE_URL_PLACEHOLDER.txt` so the final QR can be generated from the deployed URL.

Recommended free deployment: GitHub Pages. Upload `index.html`, enable Pages, then generate a QR from the resulting public URL.
